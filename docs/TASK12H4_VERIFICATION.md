馆长可从账户设置的“查看操作审计”进入 `/account/museums/[id]/audit`，查看所属博物馆已记录的全部操作类型。默认最新记录在前，每页 25 条；支持对象类型、精确对象 ID 筛选及点击对象查看其记录。

展示操作者当前显示名和 User ID、时间（UTC）、动作、对象类型与 ID；可展开事件 ID 和已有稀疏 diff。操作者删除后显示“已删除用户”，对象删除不影响历史读取。未知动作显示原始名称，包括与 JavaScript 内置属性重名的动作，不能影响页面渲染。

## 安全与行为

未登录访问转到账户登录页。服务端在每次查询重新读取数据库中的所有者身份，协作者、非成员及其他馆的 Owner 无权查看，页面统一返回 404。原馆长失去所有权后下一次请求失败；待删除馆仍保留当前 Owner 的读取权限，不为协作者开放。

所有查询包含 museum 条件，类型与对象 ID 使用参数绑定，不能依靠查询参数读取他馆记录。页码必须是 1～999999 的整数；限制对象类型和 ID 长度；重复参数等无效输入返回无筛选的规范页面。每页结果有固定上限，通过 LEFT JOIN 一次取得操作者姓名，不逐行查询对象或用户。

查询仅选取审计字段和显示名，不读取邮件地址、密码或会话凭证；diff 复用 H1～H3 writer 保存的摘要，不新增正文或照片内容。页面以 React 文本渲染字段和 diff，不执行其中的 HTML。记录链接使用编码后的参数，无缓存授权结果或公共预取入口。

原有内容、邀请及成员操作行为不变；新增的行为是馆长可读取历史审计。读取本身不修改日志。
