# B1 账号统一额度与跨馆预留自检

日期：2026-10-03。状态：本地完成，未部署。

## 实现

- users保存账号总额度；NULL代表尚未分配，不视为无限额度。
- migration30单馆原额度原值迁移；多馆而账号额度未明确分配时拒绝自动相加，并回滚本次迁移。显式运营映射保持原值。
- 创建首馆和首次额度初始化在同一事务中，后续宫殿不能重复获赠额度。
- 上传在现有BEGIN IMMEDIATE事务内，按当前馆长聚合全部自有宫殿used/reserved；任何自有馆usage未核实都拒绝上传。文件账本仍按馆，成功物理清理之后才释放容量。
- 只读审计优先展示已分配账号额度，不使用过时单馆额度覆盖；历史字段保留，不合并数据。

任务拆为迁移/首馆初始化、上传预留、防回归审计三个小步骤。旧复制服务未开放，其内部配额安全测试改为账号额度，仍验证失败不产生部分数据。
