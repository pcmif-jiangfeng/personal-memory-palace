# B2 管理员账号额度目标自检

日期：2026-10-03。状态：本地完成，未部署。

## 实现与接口契约

- 保留现有管理员宫殿选择路径，调整该馆馆长账号总额度，作用于其所有自有馆；不改内容、单馆账本或历史单馆额度字段。
- PATCH `/api/admin/museums/[id]/quota` 请求包含 `storageQuotaBytes`、`expectedQuotaBytes`、`expectedOwnerId`。必须是安全非负整数字节数及User UUID。新增owner预期值是防误改安全要求；旧页面需要刷新至新构建，不支持省略该字段的旧请求。
- 事务内复核管理员、当前owner及旧账号额度；馆长变化返回409 `STORAGE_QUOTA_OWNER_CONFLICT`，额度变化返回409 `STORAGE_QUOTA_CONFLICT`，无写入。
- 账号额度变更和最小审计原子提交；no-op不重复审计。元数据及表单明确显示“馆长账号总配额”，不误称单馆配额。

实施拆为服务/API契约与管理页面/运行验证两个小步；未新增管理员权限、套餐或依赖。
