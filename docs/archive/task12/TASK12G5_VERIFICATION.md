- `src/components/memory-management.tsx`：传入 Memory 版本，使用稳定的 Memory key，避免普通页面刷新重建展品编辑器并丢弃草稿。

## 人工验收（隔离测试版本）

1. 使用两个独立浏览器会话，分别登录同馆馆长和协作者；同时打开同一段至少有三张照片的记忆。
2. 协作者填写展品标题/说明但暂不保存；馆长修改该照片说明并保存。协作者再保存应看到冲突提示，草稿仍在，馆长的新内容未被覆盖。
3. 点击“重新加载最新内容”：取消时保留草稿，确认时加载最新数据；再次修改并保存应成功，可连续保存两次。
4. 每次让两边重新加载到相同版本，重复测试设封面、排序、从图库添加照片和移除照片；后提交的旧页面不得覆盖前一次结果。
5. 批量上传两张以上照片，确认全部成功关联，不因本页自己的并发上传产生版本冲突。若另一用户中途编辑，关联冲突应明确显示；已上传的照片仍可在照片整理台找到，不被删除。
6. 有未保存展品说明时，在同页保存基本信息或其他控件，确认刷新不会清空展品草稿；需要时复制草稿并确认加载最新内容后再保存。
