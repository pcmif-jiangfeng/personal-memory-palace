## 实现

- `/admin` 各 Museum 卡片提供整数字节配额表单；复用既有请求及错误模式，没有新依赖。
- `PATCH /api/admin/museums/[id]/quota`：先验证同源和有效 User Session/平台管理员身份，再解析输入，事务内重新检查管理员权限。
- 输入只接受 `storageQuotaBytes` 和 `expectedQuotaBytes`，均需为 0 至 `Number.MAX_SAFE_INTEGER` 的整数；不接受负数、小数、非有限值、数字字符串、缺失字段或伪造 actor 等额外字段。
- 比较原配额防止旧页面覆盖新值，冲突返回 409；Museum 不存在返回 404；未登录 401、非管理员/跨站请求 403。
- 审计：`admin.quota.update`，真实会话 actor、目标 Museum、objectType/objectId、时间，diff 只含调整前后配额。不读取或记录私人内容/凭据。修改和审计同事务，审计失败则配额回滚；未改变数值不生成伪变更。
- 不更改 `storage_used_bytes`、内容 version、ownership、membership，不删除文件；其他 Museum 的额度不受影响。
- 0 是“禁止新增上传”，不是无限额度。可以降到低于已用空间；已有内容仍可使用，后续新增上传拒绝。降低额度不撤销此前已获预留的上传，仍会计入实际已用量。
- 沿用 I2 每次读取现有配额的上传预留机制，无请求内目录扫描、无配额缓存；旧馆未完成用量重算时，调整额度不绕过就绪检查。
