## 限制与复验

- 使用 K3 同一维护命令，部署后需服务器每分钟调用；未创建外部调度。暂停调度会延迟提醒，已超过截止时间的提醒不再发送。
- 已发送或正在提交给邮件服务的邮件无法撤回；取消会使尚未领取的提醒作废，并发送取消通知。
- 发送成功是提供商接收，实际收件 / 退信仍须验收；K3 报告中的 24 小时提供商去重窗口限制仍适用。
- 人工路径：馆主确认待删除 → 检查启动通知 → 在测试库进入临近截止窗口并运行维护入口 → 确认仅一封提醒 → 取消删除 → 检查取消通知且无后续提醒。不得直接改真实生产截止时间来测试。
