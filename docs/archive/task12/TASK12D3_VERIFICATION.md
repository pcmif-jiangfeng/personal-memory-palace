# Task 12D3 — Museum Profile Settings

完成日期：2026-09-26。

## 范围与实现

- `/account` 增加名称、简介、封面设置；继续使用已有馆址编辑表单。
- 名称必填、最多80字符；简介允许为空、最多500字符。
- 封面从本馆最多60张可用照片中选择，包含当前封面；允许清除。排除其他馆、未归属照片与待删除照片。
- PATCH `/api/museums` 保持原有 `{slug}` 请求；新增 `{name,description,coverPhotoId}` 请求。两种请求分别提交，混合请求返回400，避免静默忽略馆址。
- 身份从有效 User 会话取得，Museum 从 owner_id 查找；不接受客户端指定归属。沿用同源检查。
- 资料更新在事务中完成；无变化不增加version。没有新增乐观锁、协作或审计。
- 照片查询返回普通对象，以符合 Server/Client Component 序列化要求。
