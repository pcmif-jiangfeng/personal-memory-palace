# D2 媒体与内容动作权限自检

日期：2026-10-03。结论：通过，本地实施，未推送或部署。

## 修改与原因

- photo-access.ts 去掉普通媒体读取的额外owner限制，仍由真实照片所属宫殿、已验证有效成员、active状态及物理存储键校验授权。
- scoped-memory.ts、scoped-stage.ts 在写事务中限制publication为馆长；原永久删除及分享管理馆长检查保持。
- 增加publication拒绝且无副作用测试、新邮箱邀请接受后的媒体正向/撤权/冻结测试。旧媒体测试按新规格允许真实有效成员，所有跨馆绑定、匿名、未验证、退出及撤销断言保留。
- 双馆都有授权时可独立读取B馆媒体，不代表A馆scope可写B馆资源；跨馆读写范围矩阵保持拒绝。
- 历史审计/归属测试中的publication改由馆长执行；归属测试使用成员普通编辑证明作者不被改写，审计失败回滚断言保留。

本轮全量捕获museum-owner-transfer.test.ts默认宫殿UUID断言波动。旧夹具删除私人唯一约束，转让后造出同一owner两座private馆；选择器按创建时间/ID排序，私人查询无唯一行，因UUID随机排序而不稳定。
