## 展示与保密边界

每条只显示操作者当前显示名、固定简短说明和 UTC 时间；内部事件 ID 仅作列表标识。不返回操作者 User ID、对象 ID、原始 action、原始 objectType、diff、邮箱、密码或会话信息。操作者删除后显示“已删除用户”；被删对象的内容操作事件仍可保留。

白名单明确列出 Memory/Stage 创建、编辑、关系/展陈/封面/顺序/公开范围调整、回收及恢复等内容操作，以及 Photo 上传、归档、进入删除队列。`photo.deleteQueued` 文案只表示已进入队列，不宣称物理文件已清理。

邀请、成员关系、所有权、博物馆删除生命周期、管理员受控访问及未知新动作均不展示；即使新动作以 `memory.` 等内容前缀开头，也不会自动进入活动流。要求 objectType 与已审核 action 的内容类别匹配，拒绝错配事件。未来新动作必须显式审查后加入白名单。

白名单在 SQL 查询、计数及分页前生效，SELECT 不读取 diff；不是查询完整审计后由浏览器隐藏字段。动作白名单与简短文案共用一个当前业务策略，避免安全名单和显示名单各自变化。一次 JOIN 获取姓名，没有逐条用户或对象查询。

## 权限与行为

每次请求重新授权。未登录转到账户登录页，非成员、跨馆请求、退出/被撤销成员均无权访问。pending deletion 博物馆不提供活动页，Owner 仍可按 H4 的规则查看自己的完整审计。活动权限不会赋予协作者完整审计权限。

默认最新在前，每页 25 条，同时间用事件 ID 固定排序。刷新后读取最新事件，不要求自动推送更新。有效成员能看到本馆已记录的历史内容活动，包括加入前的记录；这与现有馆级内容访问范围一致。超出记录范围显示空页；非法或重复页码跳转回第一页的规范地址。

新增可观察行为仅为活动入口和只读页面，不改变记忆、照片、成员或邀请的写入流程。
