# Personal Memory Palace — 多人协作规格

版本：2026-10-03 第一版完整稿，已通过用户整体审阅。

状态：产品决定已逐项确认，用户已授权本地实施；验收证据见 tasks/todo.md 与 docs/COLLABORATION_VERIFICATION.md。尚未授权生产迁移或部署，不将本地测试等同于上线。

## 1. 目标与文档关系

在不改变“通过照片与文字重新遇见过去”的体验前提下，支持帮助整理个人经历，以及共同保存家庭、情侣、朋友的共同经历。

[PRODUCT_CORE.md](PRODUCT_CORE.md) 定义长期产品核心，本文定义协作行为和验收；旧 Task 保留历史用途。本文替代 Task13 的单宫殿限制、仅 owner 的普通私人访问限制及禁止协作的阶段限制，不替代统一认证、邮箱验证、默认隔离和匿名只读分享。

本文不是实施任务清单。整体审阅后另行制定实施任务；不得直接按旧接口恢复功能。

## 2. 术语与空间模型

| 概念 | 准确定义 |
| --- | --- |
| 账号 / User | 邮箱登录的身份，不是宫殿；同一账号可在不同宫殿承担不同角色 |
| 宫殿 / Museum | 一组独立的照片、Memory、Stage、Note、关联、回收站、分享和成员权限；沿用现有 Museum 概念，不要求新建另一套实体 |
| 私人宫殿 | 每个账号自己的一个宫殿，可邀请协作，馆长不可转让 |
| 共同宫殿 | 额外创建的共同经历空间，不替代成员的私人宫殿，可转让馆长 |
| 馆长 | 某座宫殿唯一的管理者，不是全站管理员 |
| 协作者 | 接受邀请后加入该宫殿的已验证账号 |
| 访客 | 使用外部分享访问指定内容的人，匿名和已登录访客权限相同 |

“私人”表示默认不对外开放，不表示禁止邀请；“共同”表示共同记录，不表示多人平等拥有最高管理权。

每个账号拥有一个私人宫殿，可创建或加入共同宫殿，也可加入别人的私人宫殿。本阶段不新增共同宫殿创建数、加入数和成员数的产品限制，存储仍受馆长账号配额限制。这不代表承诺无限服务容量。

各宫殿数据不自动互通。每次操作明确目标宫殿；切换界面不改变账号身份，也不自动取得其他宫殿权限。

## 3. 权限矩阵

以下权限适用于两种宫殿；“全部”仅指当前宫殿业务内容，不包括密码、邮箱验证码、会话、其他成员账号设置或其他宫殿。

矩阵描述正常状态；共同宫殿进入待删除期后，以第 10 节的冻结规则优先，不得依据矩阵继续管理成员、分享或内容。

| 操作 | 馆长 | 有效协作者 | 外部分享访客 |
| --- | --- | --- | --- |
| 查看宫殿全部照片、Memory、Stage、Note，包括加入前的内容 | 是 | 是 | 否，仅指定分享内容 |
| 上传照片、创建 Memory、编辑任意 Memory 正文与标题、管理 Stage 和同馆关联 | 是 | 是 | 否 |
| 照片、Memory、Stage 移入回收站和恢复 | 是 | 是 | 否 |
| 永久删除内容、清空回收站 | 是 | 否 | 否 |
| 追加 Later Note | 是 | 是 | 否 |
| 编辑 Later Note | 仅本人撰写的 | 仅本人撰写的 | 否 |
| Later Note 移入回收站 | 任意作者的 | 仅本人撰写的 | 否 |
| Later Note 恢复 | 任意作者的 | 仅本人撰写的 | 否 |
| 邀请、撤销邀请、移除成员 | 是 | 否 | 否 |
| 主动退出协作 | 馆长不能以退出绕过馆长责任 | 是 | 不适用 |
| 管理外部分享 | 是 | 否 | 否 |
| 查看当前宫殿操作记录 | 是 | 是 | 否 |
| 转让共同宫殿 | 发起转让 | 作为接任者接受 | 否 |
| 删除共同宫殿、撤销整馆删除 | 是 | 否 | 否 |

Later Note 作者权限是“共同编辑全部内容”的明确例外；馆长也不能改写别人的 Note。这里的成员管理与分享管理不属于普通内容编辑。

Later Note 的恢复权限与移入回收站一致：馆长可恢复任何人的 Note，有效协作者仅可恢复本人撰写的 Note。作者身份不代替有效成员身份；作者退出或被移除后不能继续编辑、删除或恢复原宫殿的 Note，馆长仍可将其移入回收站或恢复。

服务端对每次读取、写入、媒体获取及关联操作重新验证目标宫殿与有效身份，不能仅依赖隐藏按钮、前端角色或可猜测 ID。账号未验证时不能使用协作业务。

## 4. 邀请与成员生命周期

馆长填写指定邮箱 → 对方注册或登录 → 验证邮箱 → 查看邀请 → 主动接受 → 成为协作者。

- 邀请绑定邮箱对应的账号；仅持有或转发链接不能让另一账号加入。
- 接受前不获得任何宫殿访问权；普通分享链接不能用于加入。
- 每份邀请自创建时起有效 7 天；到达截止时刻后不能再接受，须由馆长重新邀请。邀请过期不影响已经成功加入的成员。
- 只有馆长可以邀请、撤销邀请或移除成员；协作者不能管理其他成员。
- 协作者可以主动退出；退出或被移除后，服务端立即拒绝其后续宫殿读取和写入，不等待重新登录。
- 成员上传的照片、Memory、文字、作者归属和历史操作记录继续保留，不随退出或移除而删除。
- 移除协作权限不等于撤销独立分享链接；持有有效分享链接的人仍仅按分享权限查看。
- 权限撤销不能让已下载的文件或已看到的内容消失；不得以“立即失效”承诺远程收回这些副本。

- 同一宫殿、同一邮箱同时只保留一份有效邀请。重复发送沿用原邀请，不延长原截止时间。
- 邀请被撤销或过期后可重新邀请；已经是成员的账号不能再收到该宫殿的加入邀请。
- 接受与撤销同时发生时，以服务端先成功的操作为准：先撤销则接受失败，先接受则已建立成员关系，后续移除须走成员移除流程。

## 5. 馆长与转让

- 每座宫殿只有一个馆长。
- 私人宫殿始终属于原账号，不可转让；不能把它转为共同宫殿来绕过此规则，类型转换不在本阶段范围。
- 共同宫殿只能转让给现有有效协作者，由接任者主动接受后生效。
- 接受前馆长不变；成功后接任者成为唯一馆长，原馆长成为协作者。
- 转让不复制内容，不创建第二座宫殿，不改变 Memory、照片和 Note 的原作者。
- 接任账号配额不足时阻止完成转让，不删除、压缩或遗漏内容。

- 每座共同宫殿同时只允许一份待接受转让申请，自创建起 7 天有效，到达截止时刻后不能接受。
- 原馆长可撤回，接任者可拒绝；接任者退出或被移除时申请失效。
- 接受时再次验证账号身份、有效成员资格、宫殿状态、申请状态及配额，完成操作不得产生两个馆长或中间无馆长状态。
- 待删除时不能发起或接受转让，进入待删除期使已有转让申请失效；撤销删除不自动恢复该申请。

不实施账号注销、自动接任或多个馆长。

## 6. 分享

- 只有馆长可以创建、修改、关闭外部分享。
- 访客无需注册或登录；已登录访客不因登录获得额外权限。
- 分享只读，仅投影分享指定的内容，不暴露其他私人 Memory、未授权关联或账号隐私。
- 分享仍沿用博物馆视觉，不扩展为社交平台。
- 分享展示昵称，不展示邮箱或内部 User ID。
- 协作者编辑已分享内容后，分享页同步展示最新内容；分享管理界面明确提示此规则。
- 创建分享不等于创建协作邀请，两者凭证和权限不得混用。

## 7. 配额

- 一个馆长账号的私人宫殿和其担任馆长的共同宫殿，共用该账号配额。
- 协作者上传计入目标宫殿馆长账号，不计入上传者账号。
- 配额不足时阻止新增上传，不影响浏览或编辑已有内容。
- 转让时须校验接任馆长的剩余配额；不足则不完成转让。

- 以实际保留的照片文件总大小计入配额，包括优化版及选择保留的原始文件；同一实体文件不重复计算。
- 回收站和待删除宫殿的文件仍占配额，真正删除文件后才释放；软删除不立即释放额度。
- 并发上传不能突破账号额度。转让成功时该馆整体占用归入新馆长账号，原馆长不再承担该馆占用；失败不改变归属。
- 宫殿内展示该馆占用及馆长账号剩余额度，不展示馆长其他宫殿明细。

本文不规定新的配额数值、不增加付费套餐。实现前须核对现有计量口径，如不同，明确列出迁移影响，不悄悄改变已有用户额度。上传和转让并发时，权限、归属和额度检查须保证上述规则，不允许额度超额或重复归属。

## 8. 并发编辑

同一 Memory 被多人打开编辑时，后保存者不能无提示覆盖他人已保存的版本。

示例：A、B 同时打开版本 1；A 保存版本 2；B 保存时提示“内容已被其他成员更新”，保留 B 的未保存文字，供核对后重新提交。

- 冲突判断必须在服务端与保存操作一起执行，不能仅在打开页面时检查。
- 冲突失败不改变已保存数据，不自动合并文字。
- 暂不做实时协同输入、完整历史版本或一键回滚。
- “保留未保存文字”指本次交互中保留输入，不等于承诺刷新、关闭页面后自动恢复草稿。

Memory 已被移入回收站、成员被移除等情况须明确报错，不能把普通冲突重新提交变成越权写入或自动恢复。

## 9. 作者与操作记录

- Memory 显示创建者；Later Note 显示实际撰写者，不统一署名馆长。
- 后续编辑不改变原创建者；操作者另行记录。
- 关键记录包含实际操作者、操作类别、目标和时间，覆盖创建、编辑、移入回收站、恢复、永久删除。
- 成员退出后保留历史作者归属和操作记录。
- 馆长与有效协作者均可查看当前宫殿的操作记录，外部分享访客不能查看；退出或被移除的成员不再拥有查看权限。
- 操作记录展示操作者昵称，不展示邮箱或账号凭证；查看某座宫殿的记录不授予查看其他宫殿记录的权限。
- 不记录密码、验证码或认证凭证；不以操作日志代替完整历史版本。

- 操作记录显示操作发生时的昵称；以后修改昵称不改写旧记录。
- 单项内容永久删除后，仅保留对象类型、内部标识、操作者、动作和时间，不保留照片、正文或标题副本。
- 操作者以账号归属与操作时昵称对应，不因此展示邮箱或认证凭证。记录不能用于恢复已永久删除的内容。

## 10. 删除共同宫殿

馆长明确确认整座共同宫殿 → 进入 30 天待删除期 → 馆长期限内撤销或期满永久删除。

- 待删除期间所有成员不能访问业务内容，原有效外部分享链接也停止访问。
- 馆长仍需要受限的删除状态与撤销入口；这不表示能够浏览业务内容。
- 只有馆长可以撤销；协作者不能撤销或提前永久删除。
- 撤销后恢复内容和成员权限，并仅恢复删除前仍有效的分享；不重新开启之前已关闭的分享。
- 待删除期冻结成员、邀请、分享、馆长转让及其他业务操作，仅允许馆长查看删除状态和撤销删除。撤销采用删除前的成员和有效分享状态；失效的转让申请不恢复。
- 截止时间为删除操作成功时刻加 30×24 小时，页面展示准确截止时间。到达截止时刻后不能撤销，即使后台尚未清理完成也不恢复访问。
- 期满由后台执行永久删除，失败自动重试并向馆长显示状态；不得以仅隐藏界面代替实际删除。状态入口不授予查看业务内容的权限。
- 私人宫殿整体删除和账号注销本阶段不开放。已有相关入口如存在，实施前审计并关闭相应操作，不删除历史数据；不得套用共同宫殿删除流程。

## 11. 历史数据与恢复上线边界

- 不删除或重建现有账号、宫殿、照片、Memory、Stage、Note、分享及操作记录。
- 停用期间保留的旧成员关系不能自动恢复有效权限。
- 必须重新邀请、重新接受后才恢复协作权限；旧邀请也不能成为新授权旁路。
- 历史贡献内容与作者记录保留；历史归属不明时先报告，不能猜测作者或改变数据归属。
- 不因存在旧协作服务或测试就直接启用旧接口，先验证它们是否符合新规格。

## 12. 本阶段不做

跨宫殿复制或移动、私人宫殿转让或整馆删除、宫殿类型转换、多馆长平权、实时协同输入、自动文字合并、完整版本历史、一键回滚、社区、好友、关注、私信、公开评论、点赞、账号注销、新收费体系。

允许共同整理不代表允许公开内容；能查看内容不代表有跨馆复制权限；不能永久删除不代表不能移入回收站。

## 13. 验收条件（实现后逐条验证）

以下是未来验收要求，不是当前测试结果。

- [ ] A 的私人宫殿之外可创建共同宫殿；B 加入它后仍保有自己的私人宫殿。
- [ ] B 接受邀请后能查看该宫殿加入前的内容，但不能访问 A 的其他宫殿。
- [ ] 转发邀请给 C，C 不能以自己的账号接受为 B 创建的邀请。
- [ ] 邀请自创建起 7 天内可按身份规则接受；到达截止时刻后拒绝接受，馆长可重新邀请，已加入的成员不受影响。
- [ ] 重复邀请沿用原有效邀请且不延长有效期；已加入账号不能再次受邀；撤销/接受并发仅以先成功的操作生效。
- [ ] 未登录、未验证、未接受邀请以及已经退出的账号不能使用成员业务接口。
- [ ] B 可上传、创建和编辑其他成员的 Memory，搜索、统计、随机回忆仅限目标宫殿。
- [ ] B 可移入与恢复普通内容，但不能永久删除、清空回收站或删除宫殿；手工调用接口同样失败。
- [ ] B 可追加和编辑自己的 Note，不能改写 A 的 Note；馆长也不能改写 B 的 Note。
- [ ] B 仅可移入回收站或恢复自己的 Note，不能恢复 A 的 Note；馆长可恢复任意作者的 Note，已退出或被移除的作者不能继续操作原宫殿的 Note。
- [ ] B 不能邀请、移除成员或管理外部分享；可主动退出且贡献内容继续保留。
- [ ] 移除 B 后无需重登即可拒绝新读取、媒体请求和写入；旧成员记录与旧邀请不能绕过限制。
- [ ] 匿名与已登录分享访客都只读，无法读取未分享内容或获得成员权限。
- [ ] 编辑已分享内容会更新分享展示，界面事先明确提示。
- [ ] B 上传计入馆长额度；额度不足拒绝上传而不影响已有内容浏览与编辑。
- [ ] 私人宫殿转让失败；共同宫殿只有接任者接受后才转让，成功后始终只有一个馆长。
- [ ] 转让配额不足时原馆长与数据保持不变。
- [ ] 转让申请同时仅一份，7 天有效；撤回、拒绝、接任者退出或被移除后不能接受；接受时重新验证成员、状态与配额。
- [ ] 优化版、保留原始文件、回收站及待删除文件正确计量，同一实体文件不重复计量；真实删除后释放额度，并发上传不超额。
- [ ] 转让成功整体变更该馆配额承担者，失败保持归属；界面仅展示该馆占用和馆长剩余额度，不泄露其他宫殿明细。
- [ ] A 保存后 B 的过期编辑保存被拒绝，A 的内容不变，B 的未保存文字仍保留。
- [ ] 创建、编辑、移入、恢复与永久删除留下真实操作者和时间；退出不删除作者归属。
- [ ] 馆长与有效协作者可查看当前宫殿操作记录，分享访客、已退出或被移除的成员以及其他宫殿成员不能越权查看；记录展示昵称，不展示邮箱或账号凭证。
- [ ] 昵称变更不改写旧操作昵称；内容永久删除后的记录不保留标题、正文或照片副本，不能用于恢复内容。
- [ ] 共同宫殿待删除期拒绝成员业务及外部分享，馆长只能使用状态和撤销能力。
- [ ] 期限内撤销恢复内容、成员与此前有效分享，之前已关闭的分享仍关闭。
- [ ] 待删除期拒绝成员、邀请、分享管理和转让；撤销恢复删除前状态但不恢复已失效的转让申请。
- [ ] 协作者不能撤销或提前永久删除；截止时刻为删除成功后 30×24 小时，到期不可撤销；后台删除失败可重试、有状态反馈且不恢复访问。
