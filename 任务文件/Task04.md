# Task 04 — Recall & Management

## 目标

增加：

> 重新遇见过去 + 基础长期管理

能力。

---

## 1. Time Gear

人生长廊首页增加：

```text
时间齿轮
```

它是轻科技感的核心装置。

V1 不需要 3D。

---

## 2. 随机逻辑

点击 Time Gear：

```text
旋转动画
→
随机选择 Memory
→
进入 Memory Exhibition
```

随机范围：

所有：

```text
非回收站 Memory
```

必须完全随机。

不要加权。

---

## 3. Later Notes

Memory 可以追加新的文字。

规则：

- 不覆盖 Original Story
- 每条 Later Note 独立保存
- 记录创建时间
- Memory 展览页可以看到这些追加内容

---

## 4. Search

增加基础关键词搜索。

搜索字段：

```text
Memory.title
Memory.story
```

无需复杂高级筛选。

---

## 5. Related Memories

确保：

- 可以编辑 Memory 关联
- 展览页能看到关联 Memory
- 可以点击相关 Memory 继续浏览

---

## 6. Trash

Memory 和 Stage 删除后先进入回收站。

支持：

```text
恢复
```

和：

```text
永久删除
```

永久删除必须有合理确认步骤。

---

## 当前阶段不做

不要实现：

- 当年今日
- AI 推荐
- 搜索语义理解
- 图谱可视化
- 分享
- 多用户

---

## 验收标准

用户能够：

```text
点击 Time Gear
→
随机进入一段过去
```

并能够：

- 搜索标题和 Story
- 给旧 Memory 添加 Later Note
- 浏览 Related Memories
- 删除到 Trash
- 恢复误删内容
- 永久删除

完成后停止。
